How to set up your dashboard

This tool generates a branded ONE SAP dashboard link for any SAP account — no deployment needed.

1
Branding — Enter the company name, pick an accent color, and upload their logo. The live preview updates instantly.
2
Services — Choose which SAP engagement types are active (PS, MAX, CAS) and select which dashboard tabs to show.
3
Your Link — Copy the BTP link and share it with the account team. Open it directly to see the blank branded dashboard.
